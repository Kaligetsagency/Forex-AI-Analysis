# Forex AI Analysis Subscription Platform

## Environment Variables
Create a `.env.local` file in the root of your Next.js project:

# Deriv API (Get from https://api.deriv.com/)
NEXT_PUBLIC_DERIV_APP_ID=your_deriv_app_id

# Google Gemini API
GEMINI_API_KEY=your_gemini_api_key

# Snippe Monetization (https://snippe.sh/)
SNIPPE_API_KEY=snp_your_api_key_here
SNIPPE_WEBHOOK_SECRET=your_webhook_secret

# App URL (for redirects)
NEXT_PUBLIC_APP_URL=http://localhost:3000
